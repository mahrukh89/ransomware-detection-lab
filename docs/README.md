# Evidence

This directory contains concise interpretations of the authentic screenshots retained under `screenshots/`. The raw screenshots have not been altered.

Timing is reported only when it is visible in the source image. Where a capture does not display a timestamp, the documentation says so rather than inventing one.

No raw `.evtx`, packet capture, or simulator runtime log was present in the source archive, so none is fabricated or added.

See `docs/evidence-collection.md` for the complete evidence and timing map.
