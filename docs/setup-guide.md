# Setup Guide

This guide describes the implementation represented by the repository. Execute only in an isolated lab VM.

## Components

- Windows 10/11 endpoint
- Sysmon
- Wazuh Agent
- Wazuh Manager/Dashboard
- Python 3
- Dedicated directory: `C:\RansomwareLab\TestData`

## 1. Prepare the endpoint

Create the dedicated lab directory and place the simulator under `simulator/`. Confirm Python is installed.

## 2. Configure Sysmon

Review `sysmon/sysmon-config.xml`, install/apply it in the isolated VM, and verify the Sysmon service and Operational channel.

The captured run shows Sysmon 15.21 and a configuration containing Python process and `RansomwareLab` file filters.

## 3. Configure Wazuh

Enroll the Windows agent with the Wazuh Manager and confirm the agent becomes Active. Configure collection/FIM for the lab path and verify that events appear in the dashboard.

## 4. Establish a baseline

Create a small set of harmless synthetic files under `C:\RansomwareLab\TestData` and capture the clean directory/FIM state.

## 5. Run the simulator

Review `simulator/ransomware_simulator.py` and `simulator/config.json`. Run it only against the configured synthetic directory.

The default simulator creates 30 synthetic files, renames them to `.locked`, and creates `SIMULATED_RANSOM_NOTE.txt`.

## 6. Validate telemetry

Review the exact Wazuh events generated by the run. Do not infer custom-rule success from generic file-integrity alerts.

## 7. Investigate

Capture alert details, correlate timestamps and paths, separate simulator-caused events from unrelated background alerts, and record only evidence-supported conclusions.

## 8. Publish evidence

Keep screenshots and sanitized logs only. Remove credentials, personal data, public IPs, secrets, temporary files, and unrelated exports before publishing.
