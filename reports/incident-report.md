# Controlled Ransomware Simulation — Incident Report

## Executive Summary

A harmless ransomware-behavior simulation was executed against the dedicated `C:\RansomwareLab\TestData` directory. The simulator created synthetic files, renamed them to `.locked`, and created `SIMULATED_RANSOM_NOTE.txt`. SS-12 confirms the simulator reported successful completion without encryption or destructive actions; SS-13 shows the resulting synthetic artifacts.

## Environment

The supplied evidence shows:

- Windows 11 Pro — SS-01
- Python 3.14.7 — SS-03
- Sysmon service/configuration — SS-04/05
- Wazuh Agent `001` Active — SS-07/08

## Detection and Telemetry

Wazuh displayed telemetry for the lab path. SS-15 shows file activity with rules **553** and **554**. SS-17 and SS-18 show rule **553** for file-deletion activity.

The captured alerts do not demonstrate that custom rules `100100` or `100101` fired.

## Investigation

SS-19 contains a broader alert-correlation view with multiple Wazuh alerts. SS-14 and SS-16 show rule **92154** related to `taskschd.dll`. The evidence does not establish that these alerts were caused by the simulator, so they are treated as unrelated/background activity.

## Impact

No real user files are in scope. The simulator is designed to operate only on synthetic lab files and does not encrypt or destroy data.

## Validation Result

**Validated:** environment readiness, Wazuh agent visibility, simulator execution, synthetic file creation/rename behavior, and Wazuh file-activity telemetry.

**Not validated:** successful ransomware-specific custom-rule detection, simulator-specific Sysmon Event ID 1 telemetry, or a ransomware ATT&CK technique.

## Recommendations

1. Capture the exact decoded Wazuh event generated by the simulator.
2. Run the custom rules through Wazuh's rule-testing workflow and preserve the matching rule ID.
3. Capture a simulator-specific Sysmon process event if the configured Sysmon filter is intended to detect it.
4. Add raw, sanitized logs to `evidence/` in a future run.
5. Re-test benign activity to measure false positives before claiming a high-confidence ransomware detection.
